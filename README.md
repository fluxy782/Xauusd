# XAUUSD Trading Journal 📊

Journal de trading professionnel pour tracker tes trades GOLD (XAUUSD) depuis ton téléphone et PC.

## 🚀 Déployer sur Vercel (5 minutes)

### Étape 1: Télécharge les fichiers ✅
Tous les fichiers sont prêts ci-dessous.

### Étape 2: Crée un compte GitHub (gratuit)
1. Va sur https://github.com
2. Clique sur "Sign up"
3. Créé ton compte (2 min)

### Étape 3: Crée un nouveau repo
1. Va sur https://github.com/new
2. Nomme-le: `xauusd-trading-journal`
3. Clique "Create repository"

### Étape 4: Upload les fichiers
1. Clique sur "Add file" → "Upload files"
2. Drag & drop TOUS les fichiers téléchargés
3. Clique "Commit changes"

**Structure du projet:**
```
xauusd-trading-journal/
├── package.json
├── vite.config.js
├── index.html
├── README.md
└── src/
    └── main.jsx
```

### Étape 5: Déploie sur Vercel
1. Va sur https://vercel.com
2. Clique "Sign up" (tu peux utiliser ton compte GitHub)
3. Clique "Import Project"
4. Sélectionne le repo `xauusd-trading-journal`
5. Clique "Deploy"

**C'EST FINI! ✅**

Vercel te donnera une URL du style: `https://xauusd-trading-journal.vercel.app`

## 📱 Accès depuis téléphone & PC

Juste ouvre l'URL Vercel depuis n'importe quel appareil! Tes données se synchro automatiquement via le localStorage.

## 🎯 Fonctionnalités

✅ Logger tes trades (date, prix, SL, TP, lot size)  
✅ Stats automatiques (Winrate, ROI, Profit total)  
✅ Graphiques (Equity curve + P&L distribution)  
✅ Tableau détaillé avec tous tes trades  
✅ Sauvegarde en local (aucune données perdue)
